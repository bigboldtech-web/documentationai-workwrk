The **Docs** hub on the rail holds the company's writing and knowledge: **Docs**, **Canvases**, **Files**, **SOPs**, **Policies**, **Contracts** and the **Notetaker**. **Notepad** is your own private scratch pad, and it deliberately appears in none of them.

The old Library page is gone. Each of its tabs is now its own place: notes are Docs, whiteboards are Canvases, files are **Files**, and tables are the **Tables** hub. An old Library link takes you to the right one.

---

## Docs

### Finding and creating documents

The Docs hub opens on **All docs**, a list with the location, the dates updated and viewed, and the owner. Its views are **All**, **Recent**, **Mine**, **Shared with me** and **Favorites**, and the filters narrow by location, owner and date.

Create a document from **New doc** (a **Blank doc**, **From template…** or **Import…**), or from a Space or Folder's `…` menu, **New**, **Doc**, which puts the document in that Space so it shows up in the Space's tree. A doc inside a Space opens in place in Work.

### The editor

The page is a block editor. Each block is a paragraph, heading, list item, table, image, code block and so on. Type `/` to insert a block and `@` to mention someone.

Around the blocks, the page carries:

- an icon and a cover above the title
- a title that saves as you type
- a font choice (**System**, **Serif**, **Mono**) plus **Small text** and **Full width**
- **Lock page**, which makes the document read only
- the **Document outline**, for jumping between headings
- **Reading mode**
- **Open another doc beside**, to read two docs side by side

Everything saves as you type, and a save that is still pending when you navigate away still lands.

### Sub-docs

Documents nest. The **Docs inside** panel on an open document shows its sub-docs; create one with **New doc inside**.

Row actions are the same doc menu used in the sidebar and the Docs list: **Open**, **Open in new tab**, **Open beside**, **Rename**, **Copy link**, **Duplicate**, **Move to…**, **Save as template** and **Move to Trash**.

### Version history

**Page options** and the history icon both open **Version history**. It lists the saved versions of the document; picking one restores it as the current state.

### The rest of the page options

- **Copy page contents** and **Export as Markdown**
- **Ask AI**, which can summarise the doc or extract a table from it
- **Doc stats**

A doc moved to Trash goes to the one Trash in the Work sidebar, where it can be restored.

### Comments and mentions

Comments attach to a specific block. Use the comment action on a block and the thread opens in a side panel.

Mentioning someone in a document is recorded, and it shows on their **Mentions** page.

### Sharing

Share a doc from its `…` menu with **Manage access**:

- Add people at **Full access**, **Can edit**, **Can comment** or **Can view**. On a doc, Can edit also lets someone change who can open it, and Full access adds locking it, moving it to Trash and saving it as a template.
- **General access**: a doc follows where it lives, so anyone who can open its Space or Folder can open it. Turn on **Restricted** and only the people listed can open it, plus the person who made it and Admins.
- **Public link**: a read-only address anyone with the link can open without signing in, while your workspace allows public links in Workspace settings, **Access**. Turning it off stops the link working at once.
- **Private link**: a link to copy for people who already have access.

The person who made a doc keeps Full access to it.

## Files

**Files** is the company's drive: folders, uploads, preview and a place to find what you starred.

- Views: **All**, **Favorites**, **Recent** and **In Spaces**.
- **Upload**, or drop files anywhere on the page. Its arrow has **New folder**.
- Drag files onto a Space or Folder in the Work sidebar to upload them there, and move files anywhere you can add to.
- Each file can be starred, renamed, moved, previewed or deleted.

Files also attach directly to tasks, from the task's Related section. Files attached to a List's tasks show up in that List's File gallery view.

## Notepad

**Notepad** is the sticky-note panel behind the notepad icon in the top bar. **Cmd/Ctrl + Shift + E** opens a new note, and the voice capture tool writes into it.

It is a list of short notes plus the same block editor Docs uses, with autosave. What matters about it is where the notes live and who can reach them:

- A Notepad note is yours alone. Nobody else can open it, including your manager and your Admins.
- Notepad notes do not appear in Docs, in a doc picker, or in anyone else's search.

So Notepad is not "Docs, but quicker". It is the private half. Write a thought there and it stays with you; write something a colleague needs and it belongs in Docs, or on the task itself.

There is no way to turn a Notepad note into a shared doc. Copy the text across if you need it published.
