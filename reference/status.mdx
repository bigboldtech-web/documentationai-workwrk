This page exists so you never open a WorkwrK surface expecting it to work and find out the hard way.

Three labels are used, and they mean exactly this:

- **Built**: you can use it end to end today.
- **Partly built**: it works, and the gap is named. Do not rely on the missing part.
- **Coming soon**: it is not on for customers yet. Where the product shows it at all, it says so.

Ordered by hub, the way the rail is.

## Work

| What | Status | What you need to know |
| --- | --- | --- |
| Spaces, Folders, Lists | Built | Create, rename, move, duplicate, archive and delete from each `…` menu. See [Spaces and tasks](/using/spaces-and-tasks). |
| Tasks | Built | Several assignees, subtasks, checklists, comments, watchers, priority, tags, custom fields, estimates and time tracking. A task opens as a drawer at its own address. |
| Tasks in more than one List | Built | Add a task to another List; its home stays where it was. |
| Public link for one task | Built | View only, with an optional end date, while the workspace allows public links. |
| Views | Built | List, Board, Calendar, Gantt, Timeline, Workload, Team, Cards, Hierarchy, Pivot, Chart, Dashboard, Map, Doc, Canvas, Form, File gallery and Activity. Board is every List's default, and any view can be pinned as the default. See [Views](/using/views). |
| Embed views | Coming soon | The Embed tiles in **+ View** (websites, Google Sheets, Docs, Calendar, Maps, YouTube, Figma) say so and create nothing. |
| Bird's eye | Built | A whole Space, or a Folder, as columns of cards, with Focus on one List. |
| Home and My work | Built | Home is your day; My work is everything assigned to you, grouped by when it is due. |
| Everything | Built | Every task you can open, across all Spaces. |
| Dashboards and the Space Overview | Built | Widgets over your tasks. Scheduling a dashboard or view by email is not offered yet. |
| Templates | Built | One Template Center for tasks, Lists and Spaces, with **Save as template** on each. |
| Trash | Built | One Trash for everything, with **Deleted** and **Archived** tabs and type filters. Items stay until an Owner or Admin deletes them for good. Nothing is emptied automatically yet. |
| Live updates | Built | A task someone else moves appears without a refresh. |

## Planner

| What | Status | What you need to know |
| --- | --- | --- |
| Calendar | Built | Your tasks and events on a week grid. **New event** makes an event, not a task. The Team calendar shows teammates' events as Busy. |
| Meetings | Built | Meetings with attendees, notes and action items, and a guest link for outsiders to join the call. |

## AI

| What | Status | What you need to know |
| --- | --- | --- |
| Ask AI | Built | Chat that does real work, and asks first before anything other people would see. |
| AI teammates | Built | Teammates with one job each, approvals, routines, memory, group chats, teammates in Talk and in automations. See [AI teammates](/using/ai-teammates/overview). |
| AI teammates with Gmail and Google Calendar | Coming soon | Not offered to customers yet. Nothing about it shows in the product until it is. |
| An AI teammate's own browser | Coming soon | Not built. A teammate has no tool to browse the web. |
| Workflows (automations) | Partly built | The builder, runs, retries, logs and health are real. Triggers that fire today: a task is created, a task's status, assignee or field changes, a task's date arrives, on a schedule, a KPI reading is recorded through the API or an integration, and kudos is given. **Review completed**, **SOP published** and the lead triggers are listed as not yet emitting, and the builder says so. The **Ask an AI teammate** action works. |
| AI fields in Lists | Built, off until turned on | Summary, Sentiment, Categorize and Translation fields, filled when someone chooses **Fill with AI**. An Owner or Admin turns them on in Workspace settings, **Data**, **Retention & privacy**. |
| Scheduled AI updates in Talk | Partly built | A channel's Details panel can set up a daily standup or weekly project update, and **Post now** posts one. Posting on the schedule itself is not on yet, and the panel says updates post only with Post now. |
| Marketplace | Built | The modules a workspace can turn on, Talk and Tables, with links to the AI rows. |
| Integrations | Partly built | A catalogue of other tools. Each card says what is true: **Set up**, **Ask an admin to connect this**, **Connected**, or **Request this** for one not built yet. |
| Build apps | Partly built | Describe an app and get a simple data app with typed fields and rows. It builds data apps, not interfaces or logic. |

## Teams

| What | Status | What you need to know |
| --- | --- | --- |
| Directory, Org chart, Departments, Job titles, Skills | Built | Open to everyone. Owners, Admins and the People team edit placement and reporting lines. |

| Alignment and KPI reviews | Built | A manager's board of their team's KRAs, KPI compliance, SOP read rate and weekly reviews. |
| Weekly reviews | Built | A person's weekly check-in with a manager approval state. |
| Review cycles | Built | Created for everyone, a department or chosen people; a manager runs one for their own chain. My review, Team, Peer feedback and Calibration; **Finalize outcomes** can place people on the talent grid. See [Review cycles and cadences](/admin/reviews-and-cadences). |
| Talent (9-box) | Built | Place people by hand, from performance scores, or from a finalized review cycle. |
| Analytics | Partly built | Headcount, departments and performance charts, with a CSV export. Its task figures are not available yet. |
| Kudos, Candor, Surveys | Built | Kudos tagged with company values; anonymous Candor rounds; pulse surveys with audiences by department, office, people or tag. |
| Tools and Assets | Built | What the company uses and who holds what. |

| --- | --- | --- |
| Inbox and the bell | Built | Tabs for Primary, Other, Mentions, Snoozed and Cleared; desktop alerts from this browser. |
