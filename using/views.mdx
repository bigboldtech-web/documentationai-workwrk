A List holds tasks once. A **view** is a way of drawing them. Adding a Calendar view to a List does not copy anything: it is the same tasks, arranged by date.

Views appear as tabs above the List. Click a tab to switch. Drag a tab to reorder it, and the new order is saved for everyone. Right-click a tab, or use the **...** on the active tab, for its menu: **Rename**, **Pin as default view** (or **Unpin**), **Duplicate** and **Delete**. The last view on a List cannot be deleted. A row you can't use is left out.

---

## Which view a List opens on

**Board is every List's default view.** A bare link to a List opens its Board, unless someone pinned another view.

- **Pin as default view** makes a view open first for everyone on the List. The menu says so: **Opens first for everyone on this List**. Only one view is pinned at a time, and the pinned view shows a pin and sits first in the strip.
- **Unpin** takes the pin off, and the List goes back to opening on its Board.
- A private view can't be pinned for everyone on a Space List, because the rest of the List can't see it: **Only a shared view can be pinned for everyone**. On your Personal list a pinned view **Opens first for you**.

You need edit access to the List to pin or unpin a view.

## Adding a view

Click **+ View** at the end of the tab strip. The panel has three sections:

**Popular**: List, Gantt, Calendar, Doc, Board, Form, Dashboard.

**Everything else**: Table, Canvas, Activity, Workload, Team, Map, Chart, Timeline, Cards, Pivot, Hierarchy, File gallery.

**Embed**: Any website, Google Sheets, Google Docs, Google Calendar, Google Maps, YouTube, Figma.

At the foot of the panel:

- **Private view** makes the view yours alone. Nobody else on the List sees its tab.
- **Pin as default view** pins the new view as the List's default when it is made. Ticking **Private view** on a Space List unticks and turns off Pin, for the reason above.

Two honest notes on that panel:

- The **Embed** tiles are not built yet. Each one is marked as coming soon and creates nothing. The search box at the top filters the tiles by name.
- Two tiles are the same type with a different setting. **List** and **Table** are both table views; Table uses the denser grid with a horizontal scroll. **Workload** and **Team** are both the workload type; Team shows one column per assignee instead of a capacity grid.

## What each view is for

### Views that draw the task list

These all read the same filtered set of tasks and all get the toolbar filter menu.

**List / Table**: the workhorse. One row per task, inline-editable title, status pill, and a column per built-in or custom field. Rows nest subtasks under their parent, and you can drag rows up and down. The toolbar carries group by, subtask expand and collapse, a Columns button, filters, an "only my tasks" toggle, sort, CSV export and a quick search.

**Board (Kanban)**: one column per status. Drag a card between columns to change its status, or up and down to reorder it. Cards carry the same controls as a row: title, assignees, due date, priority, tags, plus a hover rail for mark complete, add subtask and the `…` menu.

**Calendar**: a month grid by due date. `+` on a day creates a task due that day; drag a chip to another day to reschedule it.

**Gantt**: a sticky name column beside a timeline. Tasks with dates render as bars you can drag to move or grab by an edge to resize; tasks with no dates park as a marker on today so they are never invisible. The Backlog toggle docks an Unscheduled and Overdue panel you can drag rows out of onto the timeline.

**Timeline**: the read-only sibling of Gantt: one lane per status, bars from start to due, undated tasks collected below. Use Gantt to edit dates, Timeline to read the plan.

**Workload**: a people-by-day capacity grid. Its **Team** variant is one column per assignee.

**Cards**: every task as a card in a grid, with the first line of the description as the card body.

**Hierarchy**: an expand and collapse tree of parent and subtask chains, with status and assignee on each node.

**Pivot**: a two-axis cross-tab with a count or a sum per cell, plus row and column totals. Axes can be status, owner, priority or any choice field.

**Chart**: bar, pie, line or a single number, grouped by status, owner, priority or a choice field, counted or summed over a numeric field. Line mode plots tasks created per week.

**Dashboard**: a fixed report for the List: stat cards plus status, priority and owner breakdowns.

**Map**: groups tasks by the value of a Location field and shows a card per place with its tasks and an open in Google Maps link. It does not draw an interactive map.

### Views that hold content instead of tasks

These do not show the task list and do not get the filter menu.

**Doc**: a document as a tab on the List, with the full editor. Create a new one or connect an existing one.

**Canvas**: a canvas as a tab, with the same autosave as a standalone canvas. People without edit rights get a read-only view.

**Form**: a form whose answers create tasks on this List. Create a new form for the List or connect an existing one. See [Tables and Forms](/using/tables-and-forms).

**File gallery**: a grid of every file attached to this List's tasks. Images get thumbnails, everything else an icon. Clicking a card opens the task that owns the file.

**Activity**: a feed of every change across every task on the List. Each row carries a chip that opens the task.

### Tasks from other Lists

A List also shows tasks whose home is another List but that were added to this one. They carry a chip with their home List's name. See [Tasks in more than one List](/using/spaces-and-tasks#tasks-in-more-than-one-list).

## Space views and Bird's eye

A Space has its own tabs: **Overview**, **Bird's eye**, **List**, **Board**, **Team**, **Calendar** and **Gantt**. A Space opens on **Overview** unless someone pinned another tab. Right-click a Space tab for **Pin as default view** or **Unpin**; that needs Full access to the Space. Calendar shows only while the Space's Calendar feature is on.

### Bird's eye

**Bird's eye** shows every List in the Space that you can open, side by side, one column per List, with each task as a card tinted by its status. It is the quickest way to see a whole Space at once.

- **Search tasks** narrows every column by title, and **Hide closed** hides finished tasks.
- Each column's **More** menu has **Open List** and **Focus**. **Show more** at the foot of a column loads the rest.
- Tasks added to a List from elsewhere show in its column too. When there are too many to show, the column says some aren't shown and links to the List.

**Focus** opens one List as columns of its own statuses. Drag a card to another column to change its status, or up and down to reorder it, and add a task at the top of any column. A strip across the top names every List: pick another to switch, or choose **Focus** again (or press Esc) to leave. Browser Back also leaves Focus.

A **Folder** has its own Bird's eye, covering its Lists and its sub-folders' Lists, on the Folder's page.

## Filtering

The **Filter** button in the toolbar, below the view tabs, opens a rule builder.

- Each rule is *field · operator · value*.
- Operators: is, is not, is set, is not set, is before, is after, is on, contains.
- Fields: status, assignee, priority, due date, tags, title, task type, and any custom field on the List.
- Rules join with **AND** or **OR**, chosen once for the whole set.
- A **hide done** switch drops anything in a Done-group status.
- A free-text search box narrows by title.

You can name and save a rule set, then reapply it later from the same menu.

The filter applies to the view on that tab, so a Calendar view and a Chart view can hold different filters on the same List.

## What is saved, and where

A view's settings are stored with the view, not in your browser, so they are the same for everyone who opens that tab, on any device.

Saved per view:

- filters, and saved filter sets
- hidden columns and the optional built-in columns you switched on (task type, start date, tags, created, updated, task ID)
- group by field and direction
- column widths
- the column-header sort (click a column heading to sort by it)
- Chart type, group by and metric
- Pivot rows, columns and metric
- Gantt zoom level and whether the backlog panel is docked
- Workload capacity settings
- which Doc, Canvas or Form a content view points at

Not saved, and personal to you while the page is open: which subtask rows you expanded, the "only my tasks" toggle, the quick search, and the toolbar's sort dropdown (as opposed to the column-header sort, which is saved).

## Columns and fields

**Columns** opens the field shelf. It manages two things at once:

- **Built-in columns.** Some are on by default (assignees, due date, priority) and hide from here. Others are off by default (task type, start date, tags, created, updated, task ID) and switch on from here.
- **Custom fields.** These are defined per List. If the Space's Custom fields feature is off, the shelf still manages built-in columns but cannot create custom fields, and custom-field columns do not render.

Hiding a column only affects the current view. The task drawer always offers every field regardless of what the view hides.

**Statuses**, in the List's `…` menu, edits the List's own status set: value, label, colour, and whether each status counts as Active, Done or Closed.
